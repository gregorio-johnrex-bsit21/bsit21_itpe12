# Web-Based OJT Monitoring System for BSIT Students of CHMSU

## Description
The OJT Attendance and Task Monitoring System is a web-based application designed for BSIT students of CHMSU deployed to partner companies. The system provides a centralized platform where the school administrator can oversee multiple companies, while company supervisors manage student attendance, assigned tasks, and working hours. Attendance recording is supervised to prevent unauthorized or fake entries, and the system automatically computes accumulated and remaining OJT hours. It also generates consolidated reports for the school to monitor student progress. The system aims to streamline OJT monitoring, reduce manual documentation, and ensure record-keeping. 

This system is designed to manage and monitor student or trainee activities during their on-the-job training (OJT). It provides tools for time tracking, task management, communication, and productivity monitoring between trainees and supervisors.

## Features

### Daily Time Record (DTR)
- Automatically computes:
  - Total accumulated hours  
  - Target hours  
  - Missed hours  
  - Remaining hours  
- Smart time adjustment:
  - If the required time-in is 7:30 AM and the user arrives earlier (e.g., 7:00 AM), the system records 7:30 AM as the official time-in  
  - The actual arrival time is still displayed for transparency  
- Logs every time-in and time-out entry for tracking and review  

### Task Management
- Supervisors can assign tasks to users  
- Users can:
  - View assigned tasks  
  - Mark tasks as completed  
  - Submit proof of completion  

### Notes
- Users can create personal notes  
- Useful for reminders, daily plans, or journaling activities  

### Notifications
- Real-time notifications when:
  - A task is assigned by a supervisor  
  - A submitted request is approved or updated  

### Chat System
- Direct communication between user and supervisor  
- Supports:
  - Text messaging  
  - Image sharing  
  - Video sharing
