# bsit21_itpe12_2026

Title: Web-Based OJT Monitoring System for BSIT Students of CHMSU

Description:

The OJT Attendance and Task Monitoring System is a web-based application designed for BSIT students of CHMSU deployed to partner companies. The system provides a centralized platform where the school administrator can oversee multiple companies, while company supervisors manage student attendance, assigned tasks, and working hours. Attendance recording is supervised to prevent unauthorized or fake entries, and the system automatically computes accumulated and remaining OJT hours. It also generates consolidated reports for the school to monitor student progress. The system aims to streamline OJT monitoring, reduce manual documentation, and ensure record-keeping.
